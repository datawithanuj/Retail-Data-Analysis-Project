# Retail Data Analysis & Visualization

> An Excel-based analysis of online retail transactions designed to uncover revenue, customer, country, and seasonal sales insights.

![Excel](https://img.shields.io/badge/Tool-Microsoft%20Excel-217346?logo=microsoftexcel&logoColor=white) ![Focus](https://img.shields.io/badge/Focus-Retail%20Analytics-0366d6) ![Status](https://img.shields.io/badge/Project-Completed-2ea44f)

## Project Overview

This project analyzes an online retail dataset to identify revenue patterns, top-performing countries, high-value customers, and seasonal trends.

## Analysis Performed

- Removed invalid transaction records
- Calculated and analyzed revenue
- Studied sales trends over time
- Identified top countries by revenue
- Identified high-value customers
- Created visualizations for business reporting

## Key Insights

- Sales show seasonal patterns, with stronger revenue toward the end of the year
- A small number of countries contribute significantly to total revenue
- High-value customers play an important role in profitability

## Tool Used

- Microsoft Excel

## Skills Demonstrated

Data cleaning · Revenue analysis · Customer analysis · Trend analysis · Business visualization · Insight communication

## Outcome

The project demonstrates how transaction-level retail data can be converted into clear business insights using a structured Excel workflow.
