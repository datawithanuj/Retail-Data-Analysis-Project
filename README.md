# Retail Data Analysis & Visualization Project

This project involves analyzing an online retail dataset to generate business insights.

## Key Tasks:
- Data cleaning by removing invalid entries
- Revenue calculation and trend analysis
- Identifying top countries and customers
- Creating visualizations for business insights

## Insights:
- Sales show seasonal trends with higher revenue at year-end
- A few countries contribute significantly to total revenue
- High-value customers play a key role in profitability

## Tools Used:
- Microsoft Excel
